# 生态研究前沿速览 | Eco Research Digest

This repository archives PDF issues of **生态研究前沿速览**.

本仓库用于保存“生态研究前沿速览”各期 PDF 报告，聚焦生态学、环境变化、生物多样性、保护生物学、全球变化生态学等方向的近期前沿研究。

## File Naming

Reports use a date-based filename:

```text
生态研究前沿速览_YYYY-MM-DD.pdf
```

## Update Workflow

Reports are generated by the local OpenClaw workflow, normalized to PDF with clickable links, and then uploaded here automatically.
