# 生态研究前沿速览 | Eco Research Digest

This repository archives PDF issues of **生态研究前沿速览**, a periodic digest of recent ecology-related research papers.

本仓库用于保存“生态研究前沿速览”各期 PDF 报告。该速览定期搜集和整理生态学、环境变化、生物多样性、保护生物学、全球变化生态学等相关学术期刊和顶刊中的最新前沿论文，提供论文基本信息、摘要翻译、中文解读、主题分类和原文链接，便于快速跟踪生态研究前沿动态。

## File Naming

Reports use a date-based filename:

```text
生态研究前沿速览_YYYY-MM-DD.pdf
```

## Update Workflow

Reports are generated by the local OpenClaw workflow, normalized to PDF with clickable source links, and then uploaded here automatically.
